# Chairman film ("Which college will they remember?")

Apple-style film for college chairmen, English, 2:38. Plays on campuschamp.in/colleges (media/marketing/colleges.mp4).
The previous features film is kept as media/marketing/colleges-features.mp4.

- script.json: narration (voice: Sarvam girish_en_documentary) · vo/: voiced lines
- timeline.py → timeline.json · score.py: generated music, mixed with the voice
- film2.html: every scene, laid out for vertical (V, 1080x1920) and widescreen (H, 1920x1080)
- build2.cjs builds film2.V.html / film2.H.html · render2.cjs renders frames · stills2.cjs for checks
