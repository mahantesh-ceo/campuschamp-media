# Campus Champ voice

The Campus Champ narration voice is made with **IndicF5** (AI4Bharat, MIT licence), which speaks
Kannada, Hindi and other Indian languages in the voice and style of a short reference recording.

`reference/` holds candidate reference voices:
- Built-in AI4Bharat prompts are downloaded by the notebook (no file needed here).
- To use **your own Campus Champ voice**, add a 8–15 second, clean, cheerful recording as
  `reference/campuschamp.wav` (only with the speaker's written consent). The notebook picks it up.

`lab/` receives the voice samples the notebook makes, for choosing a voice by ear.
